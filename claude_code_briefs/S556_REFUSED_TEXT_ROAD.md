## 2 · The edits

### 2.0 The ONE rule (charter 2) — a *reader stop*
A refusal is a **reader stop** exactly when its reason, after the prefix `the medical PC refused it: `, is `the reader refused it (line N)` with N one or more digits and nothing after the `)`. Python: `re.fullmatch(r"the medical PC refused it: the reader refused it \(line \d+\)", reason)`. SQL (one form, used in every SELECT): `reason GLOB 'the medical PC refused it: the reader refused it (line [0-9]*)' AND reason NOT GLOB '*(line *[^0-9]*)'` — or an equivalent the build proves gives the same answer as the Python on every walk row, including `(line 4x)` (not a stop). **Not** a stop: the bare `the reader refused it`, `TODAY_NOTE`, `EMPTY_NOTE`, a `KIND text -- …` reason (`note_of` 371–375: SALE_SHORT, PURCHASE, …), every `_why_not` reason, every server refusal. A stop **ends** when a `VERIFIED` row of the same `type` is received after it (any variant, any date — the page and the map agree on this). An ended stop is **dropped** — neither a file nor a loose line. **Time shapes (R3-5):** a PC refusal's `received_at` is `isoformat()` (a `T`, `+05:30`, maybe microseconds); every "after" comparison — page, map, `refused_sheet` — compares `substr(replace(received_at,'T',' '),1,19)` in SQL or `_norm_ts(...)` in Python, never raw text. Python regex: `[0-9]+`, not `\d`.
