# faults/ — incident records & fault-related artefacts

One sub-folder per major fault/finding (named `F-##_short_slug/`), holding the incident
report, the session close-out that resolved or characterised it, and any fault-specific
evidence artefacts. Code fixes live in their normal code folders; this folder is the
*paper trail*. No secrets, no PHI, tokens masked (last-4 only) — same F-31 discipline
as the rest of the repo.
