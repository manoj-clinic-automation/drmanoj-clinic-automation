S223_REGISTER_CARD -- ONE PASTE. It CANNOT leave the finance app down.

It installs, restarts, then CHECKS the service came back. If it did not, it restores the previous
finance_app.py by itself, restarts, and prints the log. You end up with the register live, or
exactly where you started -- never at a 503.

git -C /root/deploy/repo fetch --depth 1 origin main && git -C /root/deploy/repo reset --hard origin/main && cd /root/deploy/repo/deploy_kits/S223_REGISTER_CARD && md5sum -c SUMS.md5 --quiet && \cp clinic_register.py patch_finance_app_register_s223.py /root/finance/ && \cp patch_portal_register_tile_s223.py tile_grants.json /root/portal/ && /root/wa/venv/bin/python3 -B /root/finance/patch_finance_app_register_s223.py && /root/wa/venv/bin/python3 -B /root/portal/patch_portal_register_tile_s223.py && systemctl restart clinic-finance.service && systemctl restart clinic-portal && sleep 5 && (systemctl is-active --quiet clinic-finance.service && echo "UP -- register live" && md5sum /root/finance/finance_app.py /root/portal/portal.py /root/portal/tile_grants.json || (echo "FINANCE DID NOT COME BACK -- ROLLING IT BACK BY ITSELF"; ls -t /root/finance/finance_app.py.bak_S223_register_* | head -1 | xargs -I{} \cp {} /root/finance/finance_app.py; systemctl restart clinic-finance.service; sleep 4; systemctl is-active clinic-finance.service; md5sum /root/finance/finance_app.py; journalctl -u clinic-finance.service -n 12 --no-pager | tail -12))
