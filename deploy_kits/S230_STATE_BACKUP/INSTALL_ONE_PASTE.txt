[VPS] 1 · deploy clone pull:
git -C /root/deploy/repo fetch --depth 1 origin main && git -C /root/deploy/repo reset --hard origin/main

[VPS] 2 · make the job's own directory:
mkdir -p /root/state_backup

[VPS] 3 · lock that directory down:
chmod 700 /root/state_backup

[VPS] 4 · put the script in place:
\cp /root/deploy/repo/deploy_kits/S230_STATE_BACKUP/clinic_state_backup.py /root/state_backup/clinic_state_backup.py

[VPS] 5 · generate the encryption key, created mode 600 in one step:
( umask 077; openssl rand -base64 48 > <KEYFILE> )

[VPS] 6 · copy the service-account path and the folder id from the S213 conf:
grep -E '^(SA_JSON|FOLDER_ID)=' /root/finance/drive_backup.conf >> /root/state_backup/clinic_state_backup.conf

[VPS] 7 · name the key file in the conf:
printf 'ENC_KEY_FILE=%s\n' '<KEYFILE>' >> /root/state_backup/clinic_state_backup.conf

[VPS] 8 · lock the conf down:
chmod 600 /root/state_backup/clinic_state_backup.conf

[VPS] 9 · confirm the conf has exactly three lines (expect: 3):
grep -c '=' /root/state_backup/clinic_state_backup.conf

[VPS] 10 · preflight — must end "PREFLIGHT OK":
/root/wa/venv/bin/python3 /root/state_backup/clinic_state_backup.py preflight

[VPS] 11 · the first real shipment, watched:
/root/wa/venv/bin/python3 /root/state_backup/clinic_state_backup.py run

[VPS] 12 · confirm the run can state its own age:
/root/wa/venv/bin/python3 /root/state_backup/clinic_state_backup.py list

[VPS] 13 · the nightly cron, 01:50, after both finance legs:
(crontab -l 2>/dev/null; echo '50 1 * * * /root/wa/venv/bin/python3 /root/state_backup/clinic_state_backup.py run >> /root/state_backup/clinic_state_backup.log 2>&1') | crontab -

[VPS] 14 · confirm the cron line is there:
