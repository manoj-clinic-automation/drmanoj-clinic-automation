## Why the number + date rule accepts a 4-digit end
The PROBABLE rule (number + date + supplier) takes a 4-digit end of the longer number as the same number (e.g. a paper reading 21692 against Marg's 1692, as Marg truncates). This is accepted because the rule also needs the full date (year included, within 3 days) and the supplier to agree, and the number must be the only one of that supplier's bills in that date window; two series ending alike (A000213 / B/213) make no pair.
