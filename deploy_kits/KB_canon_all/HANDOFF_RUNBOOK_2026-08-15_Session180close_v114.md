## §1 — MENTAL MODELS WORTH CARRYING

1. **A return is a magnitude with its direction in the row's type** (D314). Amounts are non-negative in `sale_item` by design; the queue keeps them signed so the in-review total stays honest. **Any path moving a row from queue to spine must convert.** Forgetting that was a live 500.
2. **Identity confidence is not one number** (D315). All grades feed revenue; only the top grade feeds an audit. A wrong match in an audit names the wrong person.
3. **`ingest_day` supersedes and deletes.** Re-running an adapter for a day destroys the previous batch's rows. Any test or job that ingests must assume it is destroying what came before.
4. **A complete Marg export ends with `GRAND TOTAL :`.** Its absence is the only reliable truncation signal; the file will otherwise open cleanly and look whole.
5. **82% attribution is not a defect.** Of the pharmacy lines with no clinic ID, 29 of 31 are distinct names — one-off walk-ins, not clinic patients whose ID was missed. Roughly 17% of pharmacy revenue is counter trade. Do not chase it with cleverer matching.
6. **A checksum proves integrity, never currency** (F-88). An install kit must state which build it is.
7. **A closed row is not drift** (D316). A canonical row that genuinely cannot be recovered is closed as LOST-SUPERSEDED or LOST-RECONSTRUCTABLE, not left to halt Phase 0 forever. A halt that always fires gets waved through, and then it protects nothing.
8. **A backup regime whose failure is invisible until a document is needed is not a backup regime** (F-89). The cold-kit session count is checked at every close.

## §3 — INSTALL DISCIPLINE
Files delivered **pre-named `.new`**; install = **ONE &&-chained block**: `md5sum -c` → `cp live live.bak` → `mv/cp .new → live` → **run the smoke test as a gate** → restart ONLY on green → auto-restore from `.bak` on red. Never numbered steps; never pasted heredocs (owner terminal corrupts long pastes — ship scripts as uploads, and ship them **in a zip with a folder**). A filename is not provenance — trust the hash (F-66). **An install kit must also state WHICH BUILD it is and refuse to run if stale — a checksum proves integrity, not currency (F-88).** **The finance app AND the asset app run on system `python3`** (F-53); clinic `/root/wa` scripts use `/root/wa/venv/bin/python3`. Portal `/root/portal/`, finance `/root/finance/`. Flask route change → F-63 test-client hits on ACTUAL routes; served-HTML assertions incl. absence checks (F-79). New/altered table → `--init`/CREATE-IF-NOT-EXISTS before the page queries it (F-65). One writer per store (D235). Never slice a date string — parse it (F-78). **Finance auth is fail-closed (F-84).** **A sale return is a magnitude + a `_return` service, never a negative (D314); the review queue keeps it signed, so every queue→spine path must convert.** **`ingest_day` supersedes and deletes the day's previous batch — any test or job that ingests destroys what came before.** **If a test suite cannot be run offline, making it runnable is the FIRST task, not an optional one (F-87)** — `dev_seed_smoke_db.py` exists for exactly this; verify differentially (baseline vs modified on identical seeded data) rather than absolutely. WhatsApp go-live = DRY→live + self-send-to-own-number FIRST (D310). **Salary/PHI/finance.db never in repo or kit — `.gitignore` the PHI paths BEFORE the first `git add` (F-31/F-49).** DB mutations ship as guarded scripts (identity check + WAL-checkpointed backup + all-or-nothing txn), never ad-hoc SQL; prefer a **view change or an additive table** over anything that rebuilds a table holding live patient data (D314).
