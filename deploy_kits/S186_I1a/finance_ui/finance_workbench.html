Every booked deposit is matched against the bank. A deposit the bank never received is reported. A deposit booked where no statement reaches is reported as unevidenced — never as a pass.

Marg item-wise report — मार्ग बिल रिपोर्ट

Export from Marg as Bill wise sales statement with With Item Deta. = Yes. Check first writes nothing — it shows every day in the file, whether that day is filed, and what would be replaced. The file is never stored on the server: it is parsed and discarded before the reply is sent.
A day in the file that is not filed yet is skipped and flagged, so it can be found later. A console line does not survive the run.
